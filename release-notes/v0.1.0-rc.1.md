# BILE Workbench v0.1.0-rc.1

Public pre-release. Windows x64 unsigned portable bundle.

## Included

- Reference-only Project Model and ordered Edit Set operations.
- Existing-BILE overlay compiler with intermediate validation and atomic candidate output.
- Canonical candidate validation that independently replays edits and checks the candidate byte-for-byte.
- Integrated Project Workflow UI for project import/open/sync, compile, validation and operation history.
- Windows x64 portable one-folder application, including the required theme plugin resources.

## Validation

- GitHub Actions run 6 completed successfully on the productization PR head. Its source tree is identical to the merged `main` tree.
- Windows Python 3.11, 3.12 and 3.13 jobs each discovered 259 tests; 103 private-fixture-dependent tests per job were explicitly skipped because those fixtures are not distributed. The remaining public tests, compile check and dependency consistency check passed.
- Windows x64 one-folder package build succeeded; `BILEWorkbench.exe` and required theme plugin resources were checked.
- The bundle is unsigned.

## Not established by this release

- Real desktop launch and interactive workflow acceptance have not been recorded by CI.
- No target-game runtime acceptance is claimed. Offline parsing, preview and candidate validation do not prove that a modified resource is accepted or displayed correctly by a game.
- Full BILE structural reconstruction remains experimental/not open.
- BILE v2 remains read-only as documented; per-title/version compatibility boundaries remain in the technical reports.

## Install

Download `BILEWorkbench-Windows-x64.zip` and its `.sha256` file. Verify the checksum, extract the entire folder, then run `BILEWorkbench.exe` from inside `BILEWorkbench`. Do not move the EXE by itself.

The bundle is unsigned and may trigger a Windows SmartScreen or antivirus warning. This is a portable folder, not an installer; no automatic updater is included.
