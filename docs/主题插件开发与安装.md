# 主题插件开发与安装

## 设计原则

BILE Workbench 的宿主程序只提供两套基础主题：**基础浅色**和**基础深色**。个性化主题不写进 `app.py`，而是由外部主题插件提供。插件可以是一个文件夹，也可以是一个 `.bileplugin` 或 `.zip` 文件；两者都使用同一份 `plugin.json` 协议。

首版主题插件是纯数据插件。宿主只读取清单、UTF-8 QSS 和可选 SVG/PNG 头像，不导入或执行插件目录中的 Python 代码。这样插件的内容可见、可审计、可复制，并且不会因为主题插件而扩大 BILE/Spine 解析或写回边界。

> 插件 QSS 会在宿主基础 QSS 之后作为当前覆盖层加载。切换插件或基础主题时，应用级样式表会被完整替换，不会无限叠加旧主题。

## 文件夹插件结构

```text
my-theme/
├─ plugin.json
├─ themes/
│  ├─ light.qss
│  └─ dark.qss
└─ assets/
   └─ avatar.svg
```

`avatar.svg` 是可选的，也可以换成 PNG。清单中的所有资源路径都必须相对于插件根目录，不能使用绝对路径、反斜杠或 `..` 越界路径。

## `plugin.json` 最小示例

```json
{
  "schema": "bile-workbench-plugin/v1",
  "type": "theme",
  "id": "my-theme",
  "name": "我的主题",
  "version": "1.0.0",
  "author": "作者名",
  "description": "主题说明",
  "glass": {
    "material": "auto",
    "tint": "#202731",
    "opacity": 0.82,
    "blur": 24,
    "border": "#506070",
    "glow": "#8CC8FF"
  },
  "themes": {
    "light": "themes/light.qss",
    "dark": "themes/dark.qss"
  },
  "assets": {
    "avatar": "assets/avatar.svg"
  },
  "tags": ["custom"]
}
```

其中 `id` 必须是 2—64 位小写字母、数字、点、短横线或下划线，并且在当前插件来源中唯一。`light.qss` 和 `dark.qss` 都是必需的；插件不能只实现一个模式，从而保证切换基础主题时视觉不会突然退回宿主默认样式。`glass` 是插件自己的材质定义：`material` 可取 `auto`、`mica`、`acrylic`、`fallback` 或 `none`；`tint`、`opacity`、`blur`、`border` 和 `glow` 用于原生效果失败时生成跨平台 QSS 玻璃表面。

## 安装和切换

源码运行时，项目根目录下的 `plugins/` 会被自动扫描。把自制插件文件夹放在该目录下，或者在工作台打开 **视图 → 主题 → 导入插件文件夹**。压缩插件通过 **视图 → 主题 → 导入插件文件** 导入。导入后来源路径会写入用户设置，重新启动时会自动扫描；如插件移动或删除，刷新时会显示被拒绝的来源，但不会阻止其他插件使用。

基础浅色/深色主题在 **视图 → 主题 → 宿主基础主题** 中切换。具体插件在 **视图 → 主题 → 外部插件主题** 中切换。当前插件的名称、版本、模式和头像会显示在中央画布上方的主题徽标中；选择“不使用插件主题”即可只使用宿主基础主题。

## 预设插件

项目自带两个完全由外部文件定义的预设：`plugins/anime-claude-girl/` 提供暖金、夜紫和薰衣草风格；`plugins/anime-openai-girl/` 提供青蓝、石墨和薄荷霓虹风格。它们分别拥有自己的浅色 QSS、深色 QSS 和 SVG 头像。名称仅表示视觉灵感标签，不表示与相关公司或产品存在官方隶属关系。

## Windows 玻璃行为

当 `material` 为 `auto` 时，Windows 11 优先尝试 DWM Mica，再尝试 Acrylic；Windows 10 会继续尝试 Acrylic 的兼容 API。原生调用不会改变现有 QMainWindow 的无边框/停靠结构，也不会强制引入 GPLv3 的第三方无边框库。Windows API 不可用、系统策略关闭材质、当前平台不是 Windows 或窗口句柄不适配时，宿主会显示 `QSS 玻璃回退`，利用插件的 tint、opacity、border 和 glow 保留磨砂、半透明、边缘高光和卡片层次。

`blur` 是玻璃材质合同中的视觉强度参数，供原生实现或后续增强使用；当前跨平台 QSS 回退无法真实模糊桌面背景，因此不会虚假宣称已经完成系统级背景模糊。建议插件把 QSS 自身做成半透明表面，不要把所有控件写成完全不透明的纯色块。

## 未来扩展

如果未来需要安装式 Python 插件，可以在不破坏当前协议的前提下增加项目命名空间下的 Python Entry Point 发现；如果需要 Qt 原生动态库插件，则应单独设计版本、ABI 和签名边界。当前主题需求不执行插件代码，因此不引入这些更重的机制。
